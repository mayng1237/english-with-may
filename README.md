# English with Mây v2.0

## Main upgrade: Conversation Coach
- Five roleplay modes: Daily Life, Work, Customer Service, Travel, Job Interview
- Speak with the microphone or type
- Immediate correction of common grammar mistakes
- More-natural American English suggestions
- Coach reads prompts aloud and keeps the conversation going
- Conversation practice contributes to XP, daily goal, accuracy and streak

## Existing features
- 1,000 flashcards
- Listening, speaking, shadowing and quiz modes
- Favorites, smart review, daily goal, streak, dark mode and levels
